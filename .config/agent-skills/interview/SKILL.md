---
name: interview
description: Interview the user and write a detailed project specification. Use when the user requests a specification through an iterative interview.
---

Identify the requested output file from the user's prompt. Ask for it if the prompt does not specify one.

Interview the user in focused rounds. Ask one to three material questions per round. Use an interactive question tool when one is available.

Cover implementation, UI and UX, risks, constraints, and tradeoffs. Skip questions that the repository or prompt already answers.

Continue until the material decisions are complete. Then write the specification to the requested file.
